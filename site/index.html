给网页加一个挂件

在 HTML 中引入固定版本的脚本。把 data-nyxid 改为你的 SDK 转发服务，并在服务中登记站点来源。

HTML
<script defer
  src="https://cdn.jsdelivr.net/gh/ChronoAIProject/nyx-assistant-sdk@v0.2.0-alpha.2/browser/nyx-widget.js"
  data-nyxid="https://sdk.example.com"
  data-verification-origin="https://nyxid.ai"
  data-services="@key"></script>

权限和工具在哪里执行？

NyxID 授权
用户批准服务访问。接入应用按授予的范围请求服务。
宿主执行
SDK 校验工具参数，页面或窗口读取实时状态，并在执行时决定是否允许写入。
对话接收结果
服务适配器将工具成功、拒绝或失败的实际结果送回原会话。
